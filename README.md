#### Скрипт для TamperMonkey который позволяет скачивать фото в диалогах, постах, сохранять ссылки на твиттер, упоминания через @, и хештеги, скачивать видео с репостов или по выбору названия в диалогах
## Установка
#### Просто скопируйте код и вставьте его в новый скрипт или скачайте файл и установите его через расширение [TamperMonkey](https://www.tampermonkey.net)
